## 边界

本轮未启动 Chrome for Testing，也未替用户操纵已安装扩展。界面操作与权限授权在测试中模拟；正式 Chrome 中的授权弹窗、关闭设置页后的后台生命周期，仍需用户安装后反馈。关闭设置页不会由代码主动取消下载，下载在现有 offscreen Worker 中执行。

当前在线清单与 0.1.9 安装包的词库相同，首次点击检查应显示“当前词库已是最新版本”。有下一次词库发布后，才会出现真实在线更新预览；测试已通过构造不同版本验证完整切换路径。完整插件代码自动更新尚未实现。
