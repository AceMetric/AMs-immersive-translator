# 两档模型与免费接口配置（0.1.4）

更新：把安装包解压并覆盖**原先加载的目录**，在 Chrome 扩展管理页点击 AM 的重新加载，再刷新待译网页。不需要删除插件或重填原配置。旧配置的极速和精准均沿用原模型。

## 配置智谱

1. 在智谱开放平台申请自己的 API 密钥。打开 AM 设置 → 模型与连接 → **智谱免费**。
2. 保留预设地址 `https://open.bigmodel.cn/api/paas/v4`，填写密钥。预设型号为 `glm-4.7-flash`。
3. 点击**重新核实免费型号**，选择清单中的具体型号，再测试连接、保存。
4. 在**两档分别选择模型**中，分别指定极速、精准使用哪个已保存连接。可以保留极速使用本地 Qwen，让精准使用智谱。

2026-10-03 的[官方模型概览](https://docs.bigmodel.cn/cn/guide/start/model-overview)明确列出 `GLM-4.7-Flash`、`GLM-4-Flash-250414` 为免费文本模型。AM 优先提供这些接口预设，**尚未用个人密钥实测线上中文质量，不把预设等同于质量推荐**。名称包含 Flash 也不代表免费。

## 硅基流动与 OpenRouter

硅基流动地址 `https://api.siliconflow.cn/v1`。本次[官方价格](https://siliconflow.cn/pricing)明确列出 `XingChenAGI/Xing4.0-29B` 输入、输出均免费；本版清单只收入已确认的型号，没有依据旧截图加入 GLM-4-9B、Qwen2.5-7B 等旧型号。填写自己的密钥、重新核实清单，再保存。

OpenRouter 地址 `https://openrouter.ai/api/v1`。先点击重新核实，读取官方公开模型目录，只保留具体 `:free` ID、文本输出以及所有列明价格为零的条目；选择固定型号并保存，不使用随机 free 路由。请求同时设置零价上限，避免转入付费提供方。

[官方免费限制说明](https://openrouter.zendesk.com/hc/en-us/articles/39501163636379-OpenRouter-Rate-Limits-What-You-Need-to-Know)目前为未充值账户每分钟 20 次、每天 50 次。AM 采用保守的本机滚动 24 小时计数，初译、校润、术语分析、连接测试和重试均计入；供应商账户在其他应用中消耗的额度仍以服务端响应为准。额度耗尽会暂停，不自动换模型或服务。

免费清单有效期 30 天。到期必须重新核实；官方页面读取失败、型号无法确认为免费、清单中没有所选型号时，不继续调用。GLM/硅基流动目前只复核本版已列型号；新增免费型号需更新清单代码后再纳入。OpenRouter 可从官方目录发现新增的固定免费型号。试用赠额与商业合作额度不归入免费 API。

## 精准、思考和校润

精准档默认一次输出自然、忠实的译文，仍带相邻上下文和领域术语。**精准档不自动开启长思考**，本地与云端一致。深度思考、译后校润是独立选择，均默认关闭；兼容接口的思考控制参数需符合该服务。

开启自动校润后，先显示初译。当前阅读区域尚有待译段时，初译优先；阅读区域完成后才处理后台校润。网页每段下方的**校润本段**支持手动校润。校润仅返回固定 ID 的文字修改，保留代码、公式、强调、链接结构及锁定术语。连续两次结构失败后，本篇自动校润暂停，只提示一次；初译保留，手动入口仍可用。正确格式不保证正确语义。

设置 → 响应能力与额度可填写并发、每分钟请求数、每分钟词元预算和滚动 24 小时请求数。词元为保守估计（请求文本＋预留输出），不是供应商账单数。限流排队时间不占模型请求超时。

## 本地 Qwen 与 Hy-MT

Ollama 原生地址 `http://localhost:11434`，点击发现模型，不需要在 AM 下载模型。默认上下文 8K、并发 1、超时 180 秒，可按电脑性能调整。仅随请求传入上下文上限，不修改 Ollama 全局设置。

[Hy-MT2 官方说明](https://github.com/Tencent-Hunyuan/Hy-MT2)提供术语、背景、风格与格式约束用法。连接用户自己的兼容或 Ollama 服务后，可选“Hy-MT 专用翻译模型”：将任务及背景放入用户消息，不依赖默认 system prompt。保持 AM 校验与额度限制。未在本机部署或实测 Hy-MT；不会自动下载模型，不能把沉浸式翻译的合作额度当作 AM 的免费 API。

## 诊断与术语图

设置 → 阅读偏好可开启诊断，记录本机分阶段时间、请求数、输出长度与校验原因，最多保存 300 条。默认不记录原文或原始响应；“同时保存原文和响应”需独立开启。诊断不保存密钥或请求头，模型配置导出默认去除密钥和附加头。

术语图为默认关闭的实验开关。已补充少量歧义词的原创定义与语境关键词，关系端点严格区分原词、领域、词义，只传播一跳，最多 8 个邻居、700 字符。图邻居只是消歧提示，不会锁定未出现的词，也不会覆盖用户指定译名。尚无真实消歧质量收益证据，保持默认关闭。
