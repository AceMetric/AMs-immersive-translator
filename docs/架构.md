# 架构与约束

## 处理链

```
弹窗 / 阅读侧栏 / 设置页
       ↓ 扩展内部消息
后台服务：权限、注入、消息路由、本地接口兼容
       ↓
offscreen 文档 → Worker → 协议适配器 → 用户指定模型
                       ↕
                 IndexedDB：任务、缓存、词条
       ↓ 版本化结果
页面内容脚本：验证 → 安全 DOM → 原文下方的译文
```

内容脚本与网页隔离，模型配置只在可信扩展页面可读。所有异步结果必须匹配 sessionId 和 epoch，源段落更新后旧结果不应用。词条修正建立新会话，重译相关段落；未受影响的译文节点保留。

后台生命周期与翻译任务分离。offscreen Worker 独立执行长请求，服务 Worker 休眠/侧栏关闭仍继续。任务派发前入库；offscreen 意外关闭后，下次操作建立新文档，检查页面是否仍是原会话，恢复其持久任务，过期页面任务清理。浏览器完整退出后页面会话消失，不自动把旧文本发往模型；用户重新开始阅读。

## 格式与缓存

页面提取区分正文、标题、图注、列表与单元格，跳过纯代码、导航（默认）、编辑区和插件节点。嵌套块不会重复提取。`P` 标记保护公式/代码/引用，`O/C` 标记保留受限行内结构，`T` 标记锁定确定术语。模型不得修改标记；验证数量、内容、嵌套与段落 ID 后才恢复节点。

保护标记在请求前规范化、响应时绑定回原段落，因此缓存能跨重新开启使用，不携带旧公式 ID。术语标记包含段落唯一序号，避免一批中不同段落的同号标记表示不同术语。模型 HTML 不直接写入网页。SVG 全局字体引用复制为独立 defs，并重命名 ID。

缓存键包含正文、语言提示词、档位、学术模式、模型/地址/协议、思考策略、领域、相关译名和相邻上下文。文章分析全文样本不进入所有段落缓存键，以避免不相关修改使全篇缓存失效；精准档摘要参与缓存。容量按条数限制并按最近使用淘汰；设置提供清理入口。

## 术语与性能

`index.json` 描述独立领域包，翻译 Worker 按选定领域懒加载，设置页才加载全库。用户和长期词条优先，候选只提供提示。已确定词义本地还原指定译名，不依赖模型自行遵守译名。

本地模型上下文上限按配置控制，默认 8,192 tokens，可设为 2,048–262,144，须与实际设备及模型能力匹配。本次本机测试保持 8K 以内，遵循用户不建议超过 28K 的约束。插件使用保守的 UTF-8 字节估算并预留输出空间，压缩邻近上下文、缩小批次、在外层空白边界拆分超长段落，避免切断公式标记或格式范围。估算不是所有模型的精确 tokenizer；不可拆分的超大格式片段保留原文并提供提示。Ollama 同时接收 num_ctx，LM Studio 等兼容接口的实际上下文仍由其服务端配置。

默认最大每批 6 段、正文预算 6,000 字符，云端并发 3 / 超时 60 秒，本地并发 1 / 超时 180 秒。超长单段单独派发。读取位置优先、附近预取；远处段落待滚动处理，进度显示的是已提取段落的完成数。

极速档每段邻近上下文约 400 字符，术语分析在阅读队列空闲时运行。精准档约 1,600 字符，同样先翻译当前可见段落；学术术语/摘要分析在阅读队列空闲时运行，不阻塞首译。分析使用直接输出节省本地计算，失败可继续翻译；模型生成术语仍是本篇候选，新词触发相关段落更新。自动分析是有长度上限的样本分析，不是全篇无限上下文，也不会保证未见过的长文后部术语已识别。

限流和临时 5xx 错误最多退避重试 2 次；鉴权失败暂停。结构损坏的批次拆成单段重试；再次损坏显示原文旁的重试入口。暂停不丢弃已在运行的请求，恢复页面则取消。

## 思考适配

Ollama 原生：`think: false / true`；Claude：关闭或开启扩展思考，4.6 系列使用 adaptive；Gemini 2.5 用 budget、3 系列用 level，不能完全关闭的模型使用较低档位。未知兼容接口不假设参数，用户可选择 reasoning_effort / enable_thinking / 服务默认。

依据：[Ollama 思考](https://docs.ollama.com/capabilities/thinking)、[Claude 思考](https://platform.claude.com/docs/en/build-with-claude/extended-thinking)、[Gemini 思考](https://ai.google.dev/gemini-api/docs/thinking)。实际支持取决于模型与服务器版本；精确档始终启用更丰富的上下文和术语检查。

本地连接兼容使用 Chrome declarativeNetRequestWithHostAccess，仅去掉本扩展、已授权 HTTP 回环地址、配置路径下请求的 Origin；不放宽服务器监听地址，不修改普通网页请求。规则定义见 `src/local-network.ts`。相关接口：[Chrome 请求规则](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest)、[offscreen](https://developer.chrome.com/docs/extensions/reference/api/offscreen)。

## 结构化响应恢复（0.1.1）

Worker 将页面 UUID 映射为请求内短 ID，再映射回原段落；上下文仅作参考，去掉非待译段落的保护标记。Ollama 支持时传 `format: json`，已知 MLX 变体跳过该参数，未知后端明确拒绝该功能时记住端点/模型能力，改用相同提示词约束。接口鉴权、取消、普通 400 错误不会触发这种兼容降级。

解析器仅接受完整 JSON，允许闭合的前置思考块、围栏和少量说明文字；不解析未闭合思考块、不修补截断 JSON、不接受多个候选对象。各协议的长度结束原因统一识别，段落 ID、数量、非空及标记多重集合/嵌套仍严格校验。

模型输出失败可自动重试一次；本地请求改为直接输出，但保留原精准上下文、领域和锁定术语，并通知页面。该篇后续使用直接输出避免每批重复消耗思考预算。仍失败则按单段拆分，单段损坏不丢弃已通过校验的相邻段落。限流/临时服务错误的有限退避与模型输出恢复分别处理。

## 0.1.2 阅读队列与本地极速

页面只在配置的并发容量内派发任务，每次重新按视口与 DOM 顺序选取下一批。当前可见的跨屏段落保持阅读顺序；已完成结果在页面按派发顺序提交，以避免并发短段先显示。任务完成事件释放容量；结果携带任务归属，源文改变或会话更新时不应用旧响应。

本地极速以单段直接译文协议和短标记发送，仅携带短标题/章节及相关锁定术语，响应还原标记并作与原协议相同的保护校验。失败回退到结构化协议。缓存区分协议提示词并使用实际上下文，术语分析延后至空闲并可被新阅读任务中断。精准/云端仍保留批次及较丰富上下文。

普通正文序列化合并 HTML 空白；BR、公式、代码保留为受保护节点，明确预格式化的正文保留行结构。渲染正常正文使用 normal，并在受保护节点之外清理中文词间空格；不改变原始节点。依据与测试详见《同类项目调研与修复》。


## 0.1.3 本地精准档与可选校润

本地精准档复用短标记单段协议，但使用独立的完整中文表达约束与精简精准上下文；后台摘要与领域术语保留。`Profile.preciseThinking` 缺省为关闭，云端精准思考策略不变。`precisionPolish` 控制额外的源文/草稿联合审校，缺省关闭；校润请求不请求深度思考。

初译和校润使用相同的受保护标记映射与验证。校润在术语标记还原之前进行，必须保留指定术语和格式；坏结果保留已验证草稿，预算不足跳过额外校润。鉴权、网络错误与取消沿用队列处理。缓存区分完整提示词及两个处理选择。侧栏开关先即时更新，再持久化并通知当前阅读页面，避免页面状态尚未载入时开关没有生效。

源码来源、两次调用与参考项目三次调用的区别、中文质量边界见《精准档速度与译文质量》。

## 0.1.4 执行阶段与免费额度

`qualityProfiles` 映射两档连接；任务固定 profileId 与配置版本。短状态变更串行处理，网络请求在 pump 中独立执行；配置变更、页面源文变化和会话 epoch 均能使旧响应失效。

页面通知 Worker 当前阅读区域已无待译任务，才允许该会话自动校润。新前台任务清除空闲标识并取消后台请求；本地按接口 origin 限制为一个请求。暂停保留任务，offscreen 重建恢复尚存页面会话的初译和校润任务。

初译与校润分开缓存，初译键使用递归排序的语义配置，避免字段顺序造成误失效。校润结果键包含校润提示词版本；失败不写入已校润缓存。文字槽由草稿切分，T/P/O/C 标记留在本地，仅受限 JSON edits 可修改已有文字槽；重建再次验证。

免费目录仅允许精确供应商 origin、已核实型号和 30 天有效期。OpenRouter 请求额外限制 provider.max_price 全为零。IndexedDB 原子事务按供应商 origin 记录滚动请求和词元预算，重试、分析、校润同样计数。每次调用前重新检查免费策略和预留额度；额度耗尽、价格失效均暂停，不自动切换。限流等待与请求超时分开。

模型支持时使用 OpenAI JSON/Schema、Claude output_config.format、Gemini JSON MIME/Schema、Ollama format；明确不支持结构化参数才退回同一提示词协议。SSE/NDJSON 解码排除思考，仅交付完整且校验通过的段落对象。响应截断保留已交付段，只补缺失段落。

诊断默认关闭；开启后仅保存安全指标，源文/原始输出为独立选择，不保存密钥或请求头。术语图端点是 termKey，保守一跳候选提示，默认关闭，不引入图数据库。

暂停及自动校润失败阈值保存在本地元数据，offscreen 重建仍尊重用户暂停与本篇停用状态。仅对短时、可重入的控制消息重试一次；模型请求不因消息端口异常而盲目重新发送。重复术语保留独立出现标记，模型可读术语另有明确只读提示；不能通过合并出现次数来隐藏丢失。最终结构化提示只包含一份中文表达约束，避免相互冲突的输出要求。
