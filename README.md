# AM 学术翻译

免费、开源的 Chrome 插件。英文原文下方显示中文译文，保留公式、代码和页面结构；连接自己的云端 API 或 Ollama / LM Studio 本地模型。

首版面向英文 HTML 学术文献、教材、技术文档和普通网页。**PDF、扫描件、其他语言、商店发布和跨设备同步暂不支持。** 模型服务的费用由用户选择的供应商决定，插件没有付费功能限制。

## 安装

需要 Chrome 116 或更新版本。

1. 从 [GitHub Releases](https://github.com/AceMetric/AMs-immersive-translator/releases/tag/v0.1.4) 下载并解压 `AM-学术翻译-0.1.4.zip`；本地构建包在 `release/`。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后包含 `manifest.json` 的目录。
4. 固定 AM 图标，打开插件的“设置”，配置模型并测试连接。
5. 打开英文网页，点击插件图标中的“开始翻译当前网页”。从弹窗可打开阅读侧栏；启动后也可以点击网页右下角“译”按钮。

开发者可以直接加载项目中的 `.output/chrome-mv3`。更新代码并重新构建后，在扩展管理页点击重新加载，再刷新目标网页。

## 0.1.4：后台校润与严格免费接口

- 极速、精准分别选择模型；旧配置两档沿用原模型。云端精准也默认不请求长思考。
- 初译先显示，后台校润只修改固定 ID 的文字片段；代码、公式、链接属性、格式结构和锁定术语由本地重建。连续两次结构失败暂停本篇自动校润，保留单段入口。
- 当前阅读区域优先；初译与校润分开缓存，过期响应不覆盖新译文。完整流式译段通过校验才显示，截断后只重试缺失段落。
- 新增智谱、硅基流动和 OpenRouter 免费预设：个人密钥、固定已核实型号、额度不足暂停，无付费/供应商自动切换。尚未实测线上质量，不把型号大小或免费当作推荐依据。
- 术语图只作默认关闭的消歧实验；原词、领域、词义分开，一跳有预算的提示不覆盖用户术语。

## 0.1.3：本地精准档提速与中文表达

- 本地精准档逐段交付，保留相邻上下文、摘要与领域术语；默认直接翻译。深度思考在侧栏和模型设置中独立开启，旧配置无需重新设置。
- 按准确性、语序与搭配、衔接指代、文体和术语一致性约束中文表达，不只处理某一个客套句式。
- 可选“译后校润”再对照英文原文修改中文草稿，增加一次请求；损坏的校润结果不会覆盖通过格式校验的草稿。默认关闭以减少等待。
- 提示词、思考选择及校润选择纳入缓存区分；开关切换会更新当前页面。代码、公式和确定术语继续受保护。

同一 Lean 长段落首译实测约 88.0 秒 → 7.7 秒（8K、并发 1，旧版含加载及恢复，新版已加载；不代表整篇吞吐）。

[源码参考、AM 的取舍及实测边界](docs/精准档速度与译文质量.md)。覆盖原加载目录后重新加载插件并刷新网页，原模型配置保留。

## 0.1.2：阅读顺序、排版与本地极速

- 当前可见段落按阅读顺序处理，包括已经读到中部的跨屏长段。每次派发重新查看阅读位置，不再提前囤积多批本地任务。
- 普通正文合并 HTML 源码换行，清理中文词间多余空格；真实换行、代码和公式内部空白保留。
- 本地极速逐段及时显示，减少上下文重复和请求标记开销；保留领域词库、格式保护、失败恢复。精准与云端继续使用批次设置。
- 用户原有 Qwen 在报告页面实测：目标长段首译约 20.3 秒 → 7.1 秒（8K、并发 1）。这是单次首译对比，不是整篇吞吐保证。

[同类项目源码依据、取舍及实测方法](docs/同类项目调研与修复.md)。源码和本地安装包已更新；覆盖原来的加载目录，在扩展管理页重新加载，再刷新目标网页，无需重新配置模型。

## 0.1.1 更新与故障恢复

已有用户：将新安装包解压到**原先加载插件的同一个文件夹**并覆盖旧文件，在 `chrome://extensions` 点击 AM 插件卡片上的重新加载，再刷新待翻译网页。无需删除插件或重填模型配置。若加载的是本项目 `.output/chrome-mv3`，直接重新加载即可。

- 首译不再等待整篇术语分析；真正可见的段落排在预取段落之前。
- 翻译请求使用短段落 ID，邻近上下文去除内部标记，避免模型混入其他段落的代码/公式标记。
- 接受完整的 JSON 围栏或说明文字包装，仍严格校验段落、代码、公式和术语标记；不拼凑截断的 JSON。
- 本地模型思考占满输出预算、只返回思考或格式损坏时，自动保留上下文与术语改用直接输出重试，并提示状态。该篇后续请求沿用直接输出，重新开启翻译可再次尝试思考。
- Ollama 标准后端请求原生 JSON 输出；MLX 变体使用提示词约束并校验。其他后端明确拒绝原生 JSON 功能时自动记住兼容方式。
- 一个段落持续失败时只给该段显示重试入口，不再丢弃同批其他正常译文。

## 使用本地 Ollama / Qwen

1. 确保 Ollama 已启动，且模型已安装。本项目测试过的本机模型为 `qwen3.8:27b-mlx`，这只是本机模型 ID，不要求其他机器安装相同模型。
2. 在“模型与连接”中选择“本地模型”，协议选 **Ollama 原生**，地址填 `http://localhost:11434`。
3. 点击“发现本地模型”，选择名称；密钥通常留空。建议并发 1，超时 180 秒。可设置“本地上下文上限”，默认 8K；内存有限时先用 4K–8K，再根据实际运行情况调整。Ollama 会收到对应的 num_ctx，其他兼容服务会使用插件的请求预算，但服务实际模型上下文仍需在其服务端设置。
4. 点击“测试连接”，成功后“保存并使用”。Chrome 会要求授权这个接口地址。

插件只对自身发往已授权 HTTP 回环地址的请求去掉浏览器 Origin 请求头，以兼容拒绝扩展来源的本地服务。不会改动 Ollama 配置、启动参数或普通网页的请求，不需要把本地服务暴露到网络。规则限制在插件自身、精确服务地址及配置的路径。

LM Studio 选择对应预设，通常填 `http://localhost:1234/v1`。云端支持 OpenAI 兼容 Chat Completions、Claude Messages、Gemini GenerateContent。支持多个保存配置、附加请求头、并发和超时。

## 两个独立的选择

| 设置 | 行为 |
| --- | --- |
| 学术阅读 | 使用领域词库、上下文和本篇术语分析 |
| 普通网页 | 保留格式和已配置术语，省去自动学术分析 |
| 极速档 | 精简相邻上下文，首屏优先；支持时关闭思考，术语分析不阻塞首译 |
| 精准档 | 保留更丰富上下文、术语与中文表达约束；本地逐段交付，所有服务的深度思考与后台校润可分别开启 |

“精准”是处理策略，并不保证模型永远正确。公式/代码保护和确定术语的一致性校验在两个档位中都启用。

Ollama 原生通过 `think` 控制。Claude、Gemini 按协议及模型系列适配；不支持该参数的模型可在设置中选择“服务默认（不发送参数）”。未知兼容服务默认不附加思考参数，可显式选择 `reasoning_effort` 或 `enable_thinking`。有些模型不能完全关闭思考，极速档会使用其支持的较低档位。不同供应商需要填写其实际可用模型名称。

## 术语机制

数学、物理、计算机分别保存和按需加载。侧栏可手选领域，或根据标题和文章前部内容自动选择；自动选择结果会显示在侧栏。混合学科或选择不准时可手动切换。

| 领域 | 核心条目 | 扩展候选 |
| --- | ---: | ---: |
| 数学（含 Lean、类型论、形式化证明） | 508 | 1,003 |
| 物理 | 372 | 115 |
| 计算机 | 483 | 127 |
| 合计 | **1,363** | **1,245** |

数量来自实际构建并校验的数据，不把别名计为独立条目。核心库为项目整理与编辑检查的译名，有逐条领域和来源说明，**尚未经过领域专家逐条认证**，需要持续专业复核。扩展候选来自真实 Wikidata 英中标签，保留来源和 CC0 信息；未经审校，不强制替换。扩展库的 10,000 条是后续建设目标，首版实际有效数量为 1,245。候选中可能存在繁体、非标准译名及分类不准的条目。

优先级：个人指定 → 已确认长期术语 → 核心库 → 本篇自动术语。扩展候选仅作提示。长词组优先、词边界匹配、常见复数别名、缩写大小写规则，避免误匹配子串。

同词不同学科可以不同译名，例如数学的 `field → 域`、物理的 `field → 场`、计算机的 `field → 字段`。同一学科仍有多义词时，词条的“适用语境”帮助选择；无法区分的同级冲突暂不锁定。个人术语优先覆盖指定词义。

在“术语库”可搜索、添加、编辑、禁用，导入和导出 CSV / TSV / JSON。导入先预览；同领域、同原词、同词义的冲突默认跳过，勾选覆盖后才替换。本篇自动术语须点击侧栏确认才长期收录。新增或修正词条只重译涉及该原词/别名的段落，并丢弃过期响应。

## 阅读操作与格式保护

支持暂停/继续、显示/隐藏译文、恢复原文、失败单段重试，以及按站点开启自动翻译。目录和导航有独立开关。优先翻译阅读位置并预取邻近段落，滚动时继续，动态加载的内容自动补充。

原始代码、公式、链接和编号不替换。行内代码、MathJax、KaTeX、MathML、数学 SVG、常见 TeX 定界符以不可改写标记保护，返回后核对数量和嵌套结构，再用本地 DOM 重建。原有公式优先复制其表示并隔离 SVG 引用 ID；原始 TeX 需要渲染时使用打包在插件中的 MathJax 3.2.2 SVG，不加载远程脚本。无法渲染的 TeX 原样显示。

译文插入原段落下方，保留标题、列表、表格单元格、链接和强调。模型 HTML 作为普通文字处理，不作为网页执行。错误结果先按单段重试；仍失败会显示入口，原文保持完整。

## 数据与权限

配置和密钥保存在扩展本地存储；个人词条、译文缓存和任务状态保存在扩展 IndexedDB。内容脚本读不到模型密钥。默认设置导出剔除密钥和附加请求头。

翻译时会发送文字段落、文章标题/摘要、相邻上下文及相关术语到**你选择的模型地址**。学术模式的术语分析还会发送文章前部最多约 18,000 字符的文本样本。选择云端时这些文字会离开本机；选择本地接口则由该接口处理。插件没有统计服务、账号系统或自有翻译中转服务器。请求同时提供受保护行内公式、代码的只读文字表示（每个最多 240 字符，合计最多 2,000 字符），以帮助模型理解句意；不发送原始 DOM、HTML 属性或整块代码。原始节点仍由本地保存并重建。

首次点击用 `activeTab` 临时访问当前网页；接口域名和站点自动翻译权限按需申请。不会在安装时取得所有网页的访问权。关闭侧栏不取消任务；暂停停止派发新批次，已开始的请求仍可能完成。恢复原文会取消本篇任务并移除插件译文，缓存仍保留，可在设置页清除。

## 从源码运行

需要 Node.js 22.12+、npm。首次安装会准备 WXT 类型。

```sh
npm ci
npm run typecheck
npm test
npm run glossary:validate
npm run build
npm run release
```

开发热更新：`npm run dev`。重新生成核心领域包：`npm run glossary:build`。抓取候选数据：`npm run glossary:fetch`（公共服务可能限流，结果可能少于目标；缓存不伪造词条）。

源码布局：`entrypoints/` 扩展入口，`src/` 翻译、保护、词库和界面，`public/glossaries/` 领域包，`data/core.tsv` 可审阅的核心源词条，`tests/` 验收，`scripts/` 构建/校验/数据工具。

更多说明：[架构](docs/架构.md)、[测试与边界](docs/测试与边界.md)、[术语贡献](CONTRIBUTING.md)、[第三方许可](THIRD_PARTY_NOTICES.md)。代码 MIT；核心数据及 Wikidata 结构化标签 CC0；个人导入数据按其自己的许可使用。
